# SummitMate 隱私權政策

> **草稿（2026-11-25 依目前 App 功能重寫）。** 上線前還要補：營運者名稱與聯絡信箱、正式 AdMob 資訊、律師或法遵檢視。標有〔待補〕的地方都需要填。

**生效日期：〔待補，上線當天〕**

SummitMate（「我們」）是離線優先的登山行程與山友協作 App。本政策說明我們收集哪些資料、為什麼收集、存在哪裡，以及你能怎麼控制。

## 1. 不登入也能用

訪客模式不需要帳號。訪客的行程、裝備、餐食、收藏等資料**只存在你的手機**，不會上傳。

## 2. 登入後我們收集的資料

登入（註冊並驗證電子郵件）後，下列資料會備份到我們的雲端伺服器（PostgreSQL），以便跨裝置同步與和隊友協作：

| 類別 | 內容 | 誰看得到 |
| :-- | :-- | :-- |
| 帳號 | 電子郵件、顯示名稱、頭像（表情符號）；密碼只存 Bcrypt 雜湊，我們看不到明文 | 電子郵件只有你；顯示名稱與頭像會顯示給同行程成員與揪團相關人員 |
| 行程 | 名稱、日期、說明、節點（名稱、海拔、座標、時間、備註）、軌跡（GPX 簡化後的路線）、主要山頭 | 行程成員 |
| 裝備與餐食 | 你的裝備與餐點清單、勾選狀態（行程成員各自管理自己的） | 以行程成員的存取規則為準，上線前需對照 `docs/architecture/DATA_SYNC_AUTH.md` 再確認〔待補〕 |
| 協作 | 行程留言、投票與選項、投票結果 | 行程成員 |
| 好友 | 好友關係與邀請（只有雙方看得到對方的顯示名稱與頭像，不含 Email） | 好友與被邀請的人 |
| 收藏 | 你收藏的山岳與揪團（只存編號） | 只有你 |
| 裝備庫與範本 | 你的裝備庫、範本 | 只有你；你選擇「分享」的組合見下一項 |
| 雲端裝備組合 | 你主動分享的組合內容與名稱 | 公開：任何人；Key：知道 Key 的人；私人：只有你 |
| 揪團 | 你建立的揪團內容、報名訊息、留言、按讚、檢舉 | 揪團內容與留言為公開；「私訊」只給主辦與通過的成員；報名訊息只給主辦 |

我們不會出售你的資料，也不會把它們提供給第三方做行銷。

## 3. 位置資訊

地圖的「我的位置」使用手機定位，**只在手機上使用，不會上傳**。天氣是依行程「主要山頭」或節點的座標查詢，不是你的即時位置。

## 4. 我們用到的外部服務

使用下列功能時，你的手機或我們的伺服器會連到這些服務，它們會看到連線所需的資訊（如網路位址 IP）：

- **Open-Meteo**（天氣）：由我們的伺服器以山頭座標查詢，不帶你的帳號資訊。
- **內政部國土測繪中心（NLSC）**：政府底圖圖磚，地圖分頁顯示政府底圖時由手機直接載入。
- **魯地圖 Rudy Map（rudymap.tw）**：你選擇下載魯地圖時，手機會連線下載地圖檔，並依對方規定送出 `SummitMate/版本` 的使用者代理字串。
- **Google AdMob**（廣告）：App 內會顯示廣告。AdMob 可能使用廣告識別碼與裝置資訊投放廣告，詳見 Google 的隱私權政策。你可以在手機系統設定中重設或關閉廣告識別碼的個人化。〔待補：正式上線後的廣告設定與（如需要）同意流程〕
- **電子郵件寄送服務**：寄送註冊驗證碼。〔待補：服務商〕

App 內的外部連結（例如魯地圖官網）會用你手機的瀏覽器開啟，不使用內嵌網頁。

## 5. 權限

- **網際網路**：同步、下載地圖與查詢天氣。
- **定位（使用時）**：地圖上顯示你的位置。可以不允許，其他功能不受影響。
- **檔案選取／分享**：你匯入或匯出 GPX 時，由你選擇的檔案才會被讀取；匯出走系統分享面板。

## 6. 資料保存與刪除

- 手機上的資料可在登出時清除（登出會把裝置回到訪客狀態）。
- 你可以在「我」→「刪除帳號」刪除帳號。〔待補：刪除後雲端資料保留與清除的期限，需與實際後端行為一致〕
- 你自己分享的公開內容（雲端裝備組合、揪團）刪除帳號時的處理方式，上線前需確認並寫在這裡。

## 7. 資料安全

App 與伺服器之間使用加密連線（HTTPS）。密碼以 Bcrypt 雜湊保存。登入權杖放在手機的系統安全儲存區。沒有任何系統能保證絕對安全；帳號安全也取決於你的密碼強度與裝置防護。

## 8. 兒童

本 App 並非針對 13 歲以下兒童設計，我們不會刻意收集兒童的個人資料。

## 9. 政策變更

重大變更會在 App 內公告並更新生效日期。
