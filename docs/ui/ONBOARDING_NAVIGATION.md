# 新手引導與導覽設計（重建版）

> 2026-11-21 草案，取代舊版 `NAVIGATION.md` 的導覽結構與 Quick Tour / Tutorial / Onboarding / Welcome 四套引導。
> 範圍為第一版：行程、節點、地圖、裝備、餐食、天氣、山岳資訊；保留訪客模式與廣告；僅 iOS / Android。

## 1. 設計原則

1. **訪客優先**：不強迫登入，開啟後三步內能建立第一個行程。
2. **邊做邊學**：不做教學頁，只在「第一次需要時」出現一次性提示。
3. **一個畫面一個主要動作**：AppBar 最多 1 個動作加 1 個溢出選單，每頁最多 1 個 FAB。
4. **沒有 Drawer**：所有入口都在底部導覽或行程內。
5. **同步與離線不是使用者要管的事**：只顯示「已同步 / 同步中 / N 筆未上傳」，沒有離線模式開關。

## 2. 資訊架構

底部導覽 5 個頁籤：

| 頁籤 | 內容 | 主要動作 |
| :-- | :-- | :-- |
| 首頁 | 下一趟行程與準備清單、行程列表（進行中 / 即將出發 / 過去） | 建立行程、匯入 GPX |
| 揪團 | 找團、我的團（參加與主辦、待審核數量） | 建立揪團（FAB） |
| 地圖 | 地圖、目前位置、離線地圖 | 定位 |
| 探索 | 山岳資訊、新手推薦、戶外用品店 | 搜尋 |
| 我 | 帳號 / 訪客登入、同步狀態、設定、使用說明 | 登入（訪客）或 無（已登入） |

揪團是有日期、狀態與審核的活動，和「探索」的查閱性質不同，所以是獨立頁籤（2026-11-25 使用者決定）。

### 行程詳情（由首頁推入，不是頁籤）

只有自己時是 3 個分段：**行程 / 裝備 / 餐食**，右上選單有「邀請隊友」（開啟成員頁）。有隊友或自己不是團長時多出 **討論 / 成員**。討論再分「留言」與「投票」兩個子頁。版面見 [視覺設計規範](./DESIGN_SYSTEM.md)。

- 行程：天數切換 + 時間軸，點節點開整頁編輯，不再有「編輯模式」切換。有路線的行程在海拔剖面下方有「在地圖上看路線」。
- 裝備、餐食：同一種清單元件（分類、勾選、重量加總；熱量是選填，有填才顯示）。
- 成員與資訊：成員、邀請、天氣、分享。登入後才可邀請，訪客顯示「登入後使用」。
- AppBar：標題 + 同步狀態點 + 溢出選單（編輯、複製、範本、匯入 GPX 路線、匯出 GPX、刪除）。

### 裝備與範本（「我」推入）

「常用清單」「我的範本」「雲端裝備組合」收在同一頁，每項附一句說明，並列出把範本分享出去的步驟。範本頁直接有「分享到雲端」按鈕。

### GPX

首頁匯入會建立新行程；行程內匯入把路線加到該行程（取代原路線前先確認，航點可選擇加成節點）。路線畫在地圖頁（政府底圖與魯地圖都支援），上方標籤可關閉。

### 離線地圖

- 地圖資料來源收在左下角的資訊按鈕，點了才顯示全文與官網連結；離線地圖頁的來源說明預設收合。
- 地圖頁右下角**單一控制群組**（由上到下：定位、縮放 +、縮放 −、圖層），放在同一個直排容器裡，不分散成多個浮動按鈕，因此不會重疊。
- 離線地圖只有魯地圖（登山地形圖）：「離線地圖」頁是一張魯地圖卡片（下載、進度、取消、刪除、是否在地圖分頁使用）。沒有安裝或沒選時，地圖顯示線上的政府底圖（國土測繪中心），不提供區域下載。
- 行程有主山頭、尚未結束、且手機還沒有魯地圖時，行程分段頂部顯示提示：「出發前先下載魯地圖離線地圖，山上沒有訊號也能看」，按鈕開啟離線地圖頁。

## 3. 啟動與引導流程

```text
啟動
 └─ 讀取本地狀態
     ├─ 首次開啟 ──► 歡迎頁（一頁）
     │                ├─ [開始使用]       → 以訪客進入「首頁」
     │                └─ [登入 / 註冊]    → 認證 → 進入「首頁」
     └─ 非首次     ──► 直接進入「首頁」
```

**歡迎頁**：只有一頁，一句價值主張、三個重點（離線可用 / 行程與裝備一次規劃 / 隨時同步備份）、兩個按鈕。沒有分頁輪播，沒有「略過」。

**空狀態（行程頁，沒有行程時）**
- 主要按鈕：建立第一個行程。
- 次要按鈕：用範例行程試試看（內建一份可編輯、可刪除的範例，讓使用者先看到完整成品）。
- 取代舊版的「從雲端匯入」入口；登入後若雲端有行程，會自動出現在列表。

### 情境提示（取代 Quick Tour 與互動教學）

每則提示只在第一次需要時出現一次，使用 BottomSheet 或頁內提示條，關閉後記錄為已看過。

| 觸發時機 | 提示內容 |
| :-- | :-- |
| 第一次建立行程後 | 點時間軸上的節點可以編輯時間與備註 |
| 第一次進入裝備分段 | 勾選代表已打包，右上可依分類收合 |
| 行程有主山頭但未下載魯地圖 | 上山前建議先下載魯地圖離線地圖（行程內提示條） |
| 訪客建立第一個行程後 | 登入即可備份與分享，可略過，不阻擋（頁內提示條） |

規則：
- 一次最多顯示一則；關閉或略過只代表「這一則已看過」，**不會觸發其他流程**（修正舊版「略過後跳出匯入行程」的問題）。
- 已看過的提示記錄在本地設定。「我 → 使用說明 → 重新顯示提示」可清除記錄。
- 「使用說明」是一份靜態頁面（常見問題：如何下載離線地圖、同步如何運作、訪客與登入差異），不是互動教學。

## 4. 狀態與路由

兩個彼此獨立的狀態，避免互相糾纏：

| 狀態 | 值 | 儲存 |
| :-- | :-- | :-- |
| 引導狀態 | `needsWelcome` → `ready` | 本地設定（是否看過歡迎頁） |
| 身分狀態 | `guest` / `signedIn`（含 token 過期處理） | 本地資料庫 + 安全儲存 |
| 提示記錄 | 已看過的提示 ID 集合 | 本地設定 |

路由規則（go_router redirect）：
- 只有「需要歡迎頁」會被導到歡迎頁；**不做登入牆**。
- 需要網路或登入的功能，就地顯示「登入後使用」或重試，不跳到其他頁面。
- 從歡迎頁登入後返回，直接進入「首頁」。

## 5. 按鈕與入口預算

| 畫面 | AppBar | FAB | 其他 |
| :-- | :-- | :-- | :-- |
| 首頁 | 標題 + 同步點 | 建立行程 | 長按項目：刪除、複製 |
| 行程詳情 | 標題 + 同步點 + 溢出 | 新增節點 / 項目（依分段） | 分段切換 |
| 揪團 | 標題 | 建立揪團 | 找團／我的團分段 |
| 地圖 | 無（全螢幕） | 無 | 右下控制群組 |
| 探索 | 搜尋 | 無 | |
| 我 | 無 | 無 | 清單式選項 |

## 6. 廣告版位

- 只放在首頁行程清單、「揪團」與「探索」（山岳、用品店）清單裡，做成一張卡片（320 × 50 橫幅，標示「廣告」，上下留距）。
- 位置：行程與揪團在第 2 張卡片後（只有 1 張時在其後），探索在第 3 張後。清單沒有內容時不顯示。
- 捲動離開畫面後保留已載入的廣告，不重新請求。
- 不放在地圖、行程詳情、任何編輯畫面，也不使用插頁或全螢幕廣告。
- 載入失敗或離線時不佔位。
