# 視覺設計規範

> 2026-11-25 草案。方向由使用者確認；各頁細節、圖示與裝飾插畫依本規範延伸設計。
> 已實作：配色與全域元件樣式、行程列表與詳情、裝備、餐食、討論、探索、山岳與揪團的封面、地圖、歡迎頁、「我」、底部導覽圖示、空狀態插畫、動畫開關、App 圖示、啟動畫面與開場動畫。

## 1. 原則

1. **清爽、有手作感**：紙色底、大量留白、手繪水彩插畫。
2. **手感集中在插畫**：卡片、按鈕、輸入框用乾淨圓角，不加手繪框線。
3. **戶外看得清楚**：文字對比至少 4.5:1，觸控目標至少 44 × 44。
4. **原創素材**：參考圖只借原則，不描圖、不照抄，也不放進版控。

## 3. 字體、形狀、間距

- 字體維持現狀（系統字，中文 fallback `PingFang TC` / `Noto Sans TC`）。
- 字級跟隨系統文字大小設定，放大後版面不可裁切。

| 元素 | 圓角 |
| :-- | :-- |
| 浮動資訊卡 | 22 |
| 一般卡片 | 18 |
| 選取格（天數等） | 14 |
| 膠囊、搜尋框、主要按鈕 | 全圓 |

- 頁面左右留白 24，卡片內距 16 以上，卡片間距 8 到 16。
- 卡片用淡陰影與極淡邊線區分層次。

## 4. 插畫

| 項目 | 規則 |
| :-- | :-- |
| 線條 | 深棕、圓頭、粗細略有變化；抖動輕微 |
| 上色 | 水彩感平塗，色塊可稍微偏離線框，最多一層陰影 |
| 構圖 | 小場景立在地平線上，周圍留白；封面為滿版 |
| 元素 | 山、湖、山屋、營地、森林、雲、日月星、飛鳥 |
| 深色模式 | 夜景版本（月亮與星星取代太陽，色彩壓暗） |
| 小圖示 | 48 px 以上用彩色手繪版；導覽列與按鈕用單色簡化版 |

淺色模式的天空由上到下為 `#9FC3CC`、`#EFCFA8`、`#EEB08D`；深色模式為 `#1D3340`、`#2C4756`、`#5A5266`。

### 產生方式

插畫寫在 `app/tool/art/generate.py`，執行 `python3 -I tool/art/generate.py`（在 `app/`）轉成 `lib/shared/brand/art/art_data.g.dart`，由 App 自行繪製，不需要圖片檔或 SVG 套件。資料只記顏色角色，色碼在 `art_palette.dart`。封面主體放在畫布上方約三分之二，下方會被資訊卡蓋住。紙紋顆粒尚未實作。

### App 圖示與啟動

- 圖示為「石堆與山」：晨空、雪峰、藍綠地面與四層石堆，沿用石堆識別。圖層定義在 `generate.py` 的 `mark_*`，App 內標誌與開場動畫畫同一份資料。
- 換圖示：改圖層後依序執行 `generate.py` 與 `python3 -I -B tool/art/icons.py`（需要 Chrome 與 macOS 的 `sips`），會輸出 iOS 各尺寸與 Android 舊版、自適應圖層。Android 單色主題圖示 `ic_launcher_monochrome.xml` 需手動同步。
- 原生啟動畫面與開場動畫使用紙底色（淺 `#F1EDE2`、深 `#141C1D`，跟隨系統）。
- 開場動畫：天空、太陽、山、地面依序出現，石堆由下往上疊起。「動畫」關閉或系統減少動態效果時直接顯示完成畫面。

### 行程封面

- 系統從一組場景自動指定，不存欄位、不改資料庫與 API。
- 以行程 ID 做固定的雜湊（不用跨版本會變動的 `hashCode`），同一行程在每支手機看到同一張。

## 5. 版面

### 頁面底層（全景紙感）

- 每一頁後面都是同一幅風景：上方水彩天空（淺色為太陽與雲，深色為月亮與星星）、底部丘陵與松樹，整面覆紙紋（`assets/art/grain.png`，由 `generate.py` 產生）。
- 底層由頁面轉場加上（`BackdropTransitionsBuilder`），`Scaffold` 與 `AppBar` 為透明；彈窗與底部面板維持實色。橫向畫面只留紙底與紙紋。
- 卡片為實色加柔和陰影，不加邊線，與背景拉開層次。

### 底部切換列

地景造型：上緣是墨線丘陵，地面為深綠（淺 `#47735A`、深 `#17302A`），目前頁面以珊瑚紅圓石標示並滑動過去（關閉動畫時直接切換）。圖示一律附文字，揪團待審核數量用角標。

### 行程詳情

1. 剛開啟：滿版封面，下方浮動資訊卡（名稱、日期、重點數字），接著分段、天數、時間軸。
2. 向下捲動（以封面可收合的距離為 100%）：
   - 封面以 0.3 倍速度上移，0% 到 75% 之間不透明度由 1 降到 0.25。
   - 資訊卡在 40% 到 65% 之間淡出。
   - 65% 到 90% 之間頂部標題淡入，同時分段後方漸層成紙色；分段固定在標題下方。
   - 切到行程以外的分段時，頭部自動收合。
   - 橫向畫面（寬大於高）或高度放不下資訊卡時，只顯示標題列與分段。
3. 時間軸：彎曲的手繪虛線與手繪圓點，節點為乾淨卡片。
4. 分段選取標記是手繪底線。

沒有資料的數字（例如沒有路線時的距離與爬升）不顯示佔位值，資訊卡自動縮減。

## 6. 動畫

| 情境 | 動畫 |
| :-- | :-- |
| 行程詳情捲動 | 封面刷淡、標題收合 |
| 勾選裝備、餐食 | 系統的打勾動畫；裝備打包進度條平順前進 |
| 歡迎頁 | 風景淡入上移一次 |
| 開啟 App | 圖示組裝、石堆疊起 |

不使用持續循環的動畫，以節省電力。

- 「我」的設定提供「動畫」開關，只存在本機。關閉時持續循環與裝飾性動畫停止，捲動收合改為直接切換。
- 系統開啟減少動態效果時（`MediaQuery.disableAnimationsOf`），行為等同關閉。
