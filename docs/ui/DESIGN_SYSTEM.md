# 視覺設計規範

> 2026-11-26 修訂（收斂版）。行程列表與詳情已照本版實作；其他頁面只套到全域樣式與新封面，版面尚待逐頁改。深色模式最後再調。

## 1. 原則

1. **一個畫面一個視覺主角**：通常是水彩封面；沒有封面的頁面靠留白與資訊層次，不用裝飾填空。
2. **用資訊填滿空間**：倒數、成員、打包進度等現有資料，沒有資料就不顯示。
3. **一套規則**：固定的顏色、字級、圓角與線條圖示。
4. **戶外看得清楚**：文字對比至少 4.5:1，觸控目標至少 44 × 44。
5. **素材可商用**：參考圖只借原則，不描圖、不放進版控；字體與圖片需確認授權。

## 2. 配色

| 角色 | `ColorScheme` | 淺色 |
| :-- | :-- | :-- |
| 紙底 | `surface` | `#F6F4EF` |
| 卡片 | `surfaceContainerLowest` | `#FFFFFF` |
| 文字 | `onSurface` | `#1D2A27` |
| 次要文字 | `onSurfaceVariant` | `#5E6A66` |
| 分隔線 | `outlineVariant` | `#E8E4DA` |
| 主色（選取、進度） | `primary` | `#214E45` |
| 主色淡底 | `primaryContainer` | `#E3ECE8` |
| 主要動作 | `tertiary` | `#B9532F` |

- 一個畫面只有一個橘色按鈕。刪除等破壞性操作用 `error`，並搭配文字與確認對話框。
- 畫面程式只讀 `ColorScheme`，不寫死色碼。深色值見 `theme.dart`（暫定）。

## 3. 字體、形狀、圖示

- 標題（`headlineMedium`、`headlineSmall`、`titleLarge`、`titleMedium`）用粉圓 `Huninn`（`assets/fonts/`，SIL OFL 1.1，只有一個字重）；數字與內文用系統字。字級跟隨系統設定。
- 圓角：卡片 20、詳情上蓋版面 28、天數格 18、膠囊與主要按鈕全圓。頁面左右留白 20 到 24。
- 卡片為白底淡陰影，不加邊線。
- 圖示用線條（outlined）圖示；底部列用 `NavGlyphIcon`。

## 4. 插畫

- 水彩加細筆線、大量淡色天空、無文字與人物。封面共 6 張，放在 `app/assets/covers/`（webp，1152 × 896）。
- 由 AI 生成（`Tongyi-MAI/Z-Image-Turbo`，Apache-2.0）；提示詞與 seed 記在本機 `_local_docs/design/refined/ai/prompts.md`。圖只表達氛圍，不代表特定山岳實景。
- 行程封面以行程 ID 的固定雜湊自動指定（`coverFor`），不存欄位。
- 深色模式暫時把圖片壓暗。
- App 圖示、開場動畫、空狀態小插畫仍由 `app/tool/art/generate.py` 產生（舊手繪風，是否改版待定）。改圖示：執行 `generate.py` 後再執行 `python3 -I -B tool/art/icons.py`。

## 5. 版面

- **底部列**：貼底白色列加上緣細線，選取項目有淡色膠囊。
- **行程列表**：日期與「我的行程」標題、匯入 GPX 與新增按鈕。進行中的行程（沒有時為下一趟）用大卡：封面、倒數、成員、裝備打包進度；其他為小圖列。過去行程預設收合。橫向畫面一律用小圖列。
- **行程詳情**：封面上蓋一張版面（名稱、日期、成員、重點數字卡），下接分段、天數、時間軸。向下捲動時封面與版面淡出，標題收到頂部、分段固定；切到其他分段自動收合；橫向畫面只留標題列。
- 時間軸：一天的節點收在同一張白卡，圓形線條圖示依名稱判斷，已抵達為實心。
- 頂層頁面用大標題（`pageBar`，橫向縮回一般高度）。分類與清單項目的圖一律用 `IconBadge`（線條圖示加淡底）。
- 背景點綴（`PageAccents`，素材由 `app/tool/art/accents.py` 產生）：右上與左下的淡水彩暈染，加左下、右側兩株小植物。只用在行程、揪團、探索、「我」四個頂層頁面；固定不捲動、不加動畫，橫向畫面不顯示，深色模式降透明度。廣告橫幅放在點綴區域下方。其他頁面不加。

## 6. 動畫

| 情境 | 動畫 |
| :-- | :-- |
| 行程詳情捲動 | 封面與版面淡出、標題收合 |
| 勾選裝備、餐食 | 系統打勾動畫；打包進度條前進 |
| 歡迎頁 | 封面淡入上移一次 |
| 開啟 App | 圖示組裝、石堆疊起 |

不使用持續循環的動畫，以節省電力。

- 「我」的設定提供「動畫」開關，只存在本機。關閉時持續循環與裝飾性動畫停止，捲動收合改為直接切換。
- 系統開啟減少動態效果時（`MediaQuery.disableAnimationsOf`），行為等同關閉。
