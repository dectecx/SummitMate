# 視覺設計規範

> 2026-11-28 修訂（依設計回饋：懸浮底部列、系統無襯線字、細框卡片、模糊背景）。深色模式最後再調。

## 1. 原則

1. **一個畫面一個視覺主角**：通常是水彩封面；沒有封面的頁面靠留白與資訊層次，不用裝飾填空。
2. **用資訊填滿空間**：倒數、成員、打包進度等現有資料，沒有資料就不顯示。
3. **一套規則**：固定的顏色、字級、圓角與線條圖示。
4. **戶外看得清楚**：文字對比至少 4.5:1，觸控目標至少 44 × 44。
5. **素材可商用**：參考圖只借原則，不描圖、不放進版控；字體與圖片需確認授權。

## 2. 配色

| 角色 | `ColorScheme` | 淺色 |
| :-- | :-- | :-- |
| 紙底 | `surface` | `#F6F4EF` |
| 卡片 | `surfaceContainerLowest` | `#FFFFFF` |
| 文字 | `onSurface` | `#1D2A27` |
| 次要文字 | `onSurfaceVariant` | `#5E6A66` |
| 分隔線、卡片外框 | `outlineVariant` | `#DBD6C9` |
| 主色（選取、進度） | `primary` | `#214E45` |
| 主色淡底 | `primaryContainer` | `#E3ECE8` |
| 主要動作 | `tertiary` | `#B9532F` |

- 一個畫面只有一個橘色按鈕。刪除等破壞性操作用 `error`，並搭配文字與確認對話框。
- 畫面程式只讀 `ColorScheme`，不寫死色碼。深色值見 `theme.dart`（暫定）。

## 3. 字體、形狀、圖示

- 全部使用系統無襯線字（iOS 為蘋方，Android 為 Noto Sans CJK），不內嵌字體；標題（`headlineMedium`、`headlineSmall`、`titleLarge`、`titleMedium`）用粗體。字級跟隨系統設定。
- 圓角：卡片 20、詳情上蓋版面 28、天數格 18、膠囊與主要按鈕全圓。頁面左右留白 20 到 24。
- 卡片、清單群組、天氣面板為白底加 1 px 外框（`outlineVariant`），不加陰影；陰影只留給浮在地圖或圖片上的控制項。
- 圖示用線條（outlined）圖示；底部列用 `NavGlyphIcon`。

## 4. 插畫

- 水彩加細筆線、大量淡色天空、無文字與人物。封面共 6 張，放在 `app/assets/covers/`（webp，1152 × 896）。
- 由 AI 生成（`Tongyi-MAI/Z-Image-Turbo`，Apache-2.0）；提示詞與 seed 記在本機 `_local_docs/design/refined/ai/prompts.md`。圖只表達氛圍，不代表特定山岳實景。
- 行程封面以行程 ID 的固定雜湊自動指定（`coverFor`），不存欄位。
- 圖片顯示時降低彩度（`CoverImage`，0.7），讓文字與資料較清楚。
- 深色模式暫時把圖片壓暗。
- 空狀態與使用說明的插畫（`IllustrationView`）是同一批水彩封面做柔邊橢圓裁切；之後可換成專屬小插畫。
- App 圖示與開場動畫仍由 `app/tool/art/generate.py` 產生（舊手繪風，水彩版待生圖後讓使用者挑選）。改圖示：執行 `generate.py` 後再執行 `python3 -I -B tool/art/icons.py`。

## 5. 版面

- **底部列**（`AppNavBar`）：懸浮的玻璃膠囊，邊緣會折射後方內容；用 `liquid_glass_widgets`（固定 1.22.0，MIT）繪製，各平台一致，套件只在 `nav_bar.dart` 與啟動時使用。高 60、最寬 340；選取項目的主色淡底（淺色透明度 0.22）同時包住圖示與文字；膠囊白色透明度 0.8、模糊 8，未選中的圖示與文字用主文字色，讓它在地圖與圖片上看得清楚。系統開啟高對比時由套件改為霧面；App 的動畫開關關閉時停止動態。所有分頁內的頁面都延伸到列的下方：有指定 `padding` 的清單要在底部加 `MediaQuery.paddingOf(context).bottom`；貼底的輸入列同樣要加。浮動按鈕由 `AppShell` 提供的 `viewPadding` 自動停在列的上方。實機效能（尤其 Android）尚未量測。
- **首頁**：日期與「我的行程」標題、新增按鈕。進行中的行程（沒有時為下一趟）用大卡：封面、倒數、成員；第一張大卡列出準備清單（節點、裝備打包、餐食、離線地圖），點一下開到對應位置。其他進行中大卡顯示打包進度，其餘為小圖列。過去行程預設收合。橫向畫面一律用小圖列。
- **行程詳情**：封面上蓋一張版面（名稱、日期、成員、重點數字卡），下接分段、天數、時間軸。向下捲動時封面與版面淡出，標題收到頂部、分段固定；切到其他分段自動收合；橫向畫面只留標題列。
- 時間軸：一天的節點收在同一張白卡，圓形線條圖示依名稱判斷，已抵達為實心。
- 裝備與餐食分類圖示統一由 `gearIcon`、`mealIcon` 提供。詳情頁名稱寫在風景卡上，標題列不重複。
- 頂層頁面用大標題（`pageBar`，橫向縮回一般高度）。第一層頁面的新增動作放右上角（首頁、揪團）；行程內隨分段改變的新增動作用右下浮動按鈕。分類與清單項目的圖一律用 `IconBadge`（線條圖示加淡底）。
- 背景點綴（`PageAccents`，素材由 `app/tool/art/accents.py` 產生）：右上與左下的模糊水彩暈染，不放植物或其他有輪廓的裝飾。首頁、揪團、探索、「我」四個頂層頁面用兩個角落的暈染；沒有封面的瀏覽型內頁（裝備與範本、常用清單、範本、雲端組合、好友、收藏、使用說明、離線地圖、管理申請、邀請隊友）用 `PageAccents.inner`：只有右上角、濃度一半。表單、地圖、有封面的頁面、行程的各分段與系統授權頁不加。固定不捲動、不隨鍵盤移動、不加動畫，橫向畫面不顯示，深色模式降透明度。
- **整頁、底部面板、對話框**：建立或編輯行程、節點、揪團等長表單用整頁（`showFormPage`）；裝備、餐食、投票、邀請等快速輸入用底部面板（`showFormSheet`）；確認用對話框。很少人填的欄位收進「更多選項」（`MoreOptions`）。
- **討論**：訊息一律靠左（頭像、名稱、時間、內文），回覆縮排並以線條接到上層訊息。

## 6. 動畫

| 情境 | 動畫 |
| :-- | :-- |
| 行程詳情捲動 | 封面與版面淡出、標題收合 |
| 勾選裝備、餐食 | 系統打勾動畫；打包進度條前進 |
| 歡迎頁 | 封面淡入上移一次 |
| 開啟 App | 圖示組裝、石堆疊起 |

不使用持續循環的動畫，以節省電力。

- 「我」的設定提供「動畫」開關，只存在本機。關閉時持續循環與裝飾性動畫停止，捲動收合改為直接切換。
- 系統開啟減少動態效果時（`MediaQuery.disableAnimationsOf`），行為等同關閉。
